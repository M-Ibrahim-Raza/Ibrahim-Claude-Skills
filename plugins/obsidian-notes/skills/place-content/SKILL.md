# Place Content

Take a point or piece of content already given to you and place it in the single most suitable **existing** note. Never create a new file — if nothing existing fits, say so and stop instead of inventing a home for it. Creating a new note is `search-and-add-concept`'s job, not this one.

Never use em dashes (—). Use a comma, period, or rephrase instead. This applies to all output: chat explanations and note content.

## The run

1. Use the content exactly as given. If nothing concrete was handed to you, ask what to place — do not invent or expand it.
2. Search the vault for notes related to its terms, names, and concepts. Read every real candidate in full before deciding; a filename match is not enough.
3. Pick the single best existing note.
   - If one note is clearly the right home, use it.
   - If several are plausible, pick the one whose scope and heading structure the content most naturally extends, and say in the confirmation why you picked it over the runners-up.
   - If none fit, stop — say so, and ask whether to create a new note instead.
4. Insert it under a heading that fits, matching that note's existing style. If no heading fits, add one in that note's existing heading style — never invent a new structure for the note.
5. Add nothing beyond what was given — no new facts, no filler, no commentary.
6. Reply with a one-line confirmation: the note, the heading, and the wikilink.

## Red flags

- Creating a new file instead of saying none fit → stop and ask instead.
- Rewording or expanding the content instead of placing it verbatim → place it as given.
- Placing into the first plausible note instead of reading every candidate → read them all first.
- Inventing a heading structure instead of matching the note's own → match what's already there.
